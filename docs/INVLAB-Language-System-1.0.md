# INVLAB Language System 1.0

> Documento fundador · Versão 1.0 · Julho 2026

---

## O que é este documento

Este documento define a linguagem oficial da plataforma INVLAB.
Ele não pertence a nenhum simulador específico. Pertence ao ecossistema inteiro.

> A interface deve conversar como um bom planejador financeiro.
> Ela não vende sonhos. Ela organiza caminhos.

Qualquer módulo criado — Wizard, Simulador PRO, Noah, Mobile, ou qualquer produto futuro —
deve falar a mesma língua.

## Vocabulário Oficial

### Termos fixos — idênticos em todo o ecossistema

| Conceito | ✅ Palavra Oficial | ❌ Nunca usar |
|---|---|---|
| Renda projetada | **Sua renda na aposentadoria** | Renda Mensal Prevista |
| Objetivo de renda | **Sua meta de renda** | Meta Mensal |
| Patrimônio acumulado | **Patrimônio estimado** | Patrimônio Projetado |
| Valor para herdeiros | **O que você vai deixar** | Herança Projetada |
| Investimento adicional | **Quanto investir a mais** | Aporte Adicional Necessário / PMT |
| Resultado positivo | **Você está no caminho certo.** | Superávit |
| Resultado negativo | **Ainda falta...** | Déficit |

### Subtítulos obrigatórios

| Card | Subtítulo obrigatório |
|---|---|
| Sua renda na aposentadoria | *Em valores de hoje.* |
| Sua meta de renda | *Valor informado por você.* |
| Patrimônio estimado | *Saldo previsto no início da aposentadoria.* |
| O que você vai deixar | *Estimativa para seus herdeiros.* |

### Estratégias de renda

| ❌ Nome técnico | ✅ Nome na interface |
|---|---|
| Renda Vitalícia Perpétua | Para a vida toda — sem usar o capital |
| Período Determinado (Preservar 20%) | Por um período — preservando parte do capital |
| Estratégia Esgotável | Por um período — usando o capital aos poucos |

## Palavras proibidas na interface

Estas palavras pertencem ao motor matemático. O usuário nunca deve vê-las.

`PMT` · `Fisher` · `Taxa Real` · `Taxa Nominal` · `Déficit` · `Superávit` · `Esgotável` · `Perpétua`

## Tom de Voz

### Sempre transmitir

| Qualidade | Na prática |
|---|---|
| Tranquilidade | Déficit vira "ainda falta um pequeno ajuste". O caminho existe. |
| Planejamento | "Seu planejamento atual" — reforça disciplina, não sorte. |
| Clareza | Um usuário sem conhecimento financeiro entende em 5 segundos. |
| Confiança | Futuro simples: "você precisará". Não condicional: "você precisaria". |

### Nunca transmitir

`urgência` · `culpa` · `euforia excessiva` · `alarmismo`

### Tempos verbais

| ❌ Evitar (condicional) | ✅ Preferir (futuro simples) |
|---|---|
| você precisaria investir | você precisará investir |
| seria necessário | será necessário |
| poderia atingir | poderá atingir |

## Adaptação contextual

O vocabulário é fixo. O tom e o nível de detalhe se adaptam ao produto.
Isso não é incoerência — é adequação ao contexto.

| | 🧭 Wizard | 📊 Simulador PRO |
|---|---|---|
| Postura | Conduz, conversa, orienta | Consulta, compara, aprofunda |
| Card aporte — título | "Sugestão para atingir sua meta" | "Quanto investir a mais" |
| Aporte — detalhe | Mostrar "totalizando R$ X/mês" | Valor direto, sem totalizador |
| Origem da renda | Seção completa com breakdown | Não necessário |
| INSS | Caixa dedicada explicativa | Integrado ao resultado |
